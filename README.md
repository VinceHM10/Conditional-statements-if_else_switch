# 🚀 JavaScript Conditional Statements Practice

## JSE#2

A JavaScript practice project focused on controlling program flow with conditional statements. It covers `if`, `else if`, `else`, and `switch` statements. This project forms part of my study and preparation workflow for the **JavaScript Certified Entry-level (JSE)** certification.

## 📌 Core Learning Objectives

- Use conditions to make decisions in a program.
- Compare values and evaluate expressions.
- Choose between `if...else` and `switch` for different kinds of decisions.
- Understand how the order and matching of conditions affect which code runs.

## 🛠️ Tech Stack & Environment

- **Runtime:** Node.js v20+ (or compatible LTS version)
- **Development environment:** macOS (Mac Pro M5 MAX) / Visual Studio Code
- **Package Management:** Ready for `npm` / Express.js integration
